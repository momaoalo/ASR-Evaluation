# سياسة تنظيف النصوص — الوضع الحالي

المشروع يقارن **النص المرجعي (Ground Truth)** وناتج ASR باستخدام
**نفس قواعد التنظيف**، ويحتفظ بالنصين الأصليين دون تغيير. التحويلات
اختيارات *قياس* وقد تخفي فروقًا في المعنى؛ وليست تصحيحًا لغويًا مضمونًا.

## الوضعان المعروضان في الواجهة

- **Cleaning (`normalized`)**: سياسة ثابتة مصدرها
  [`evaluation/profiles.py`](../evaluation/profiles.py) بواسطة
  `get_cleaning_profile()`. تشمل قواعد الحروف العربية والألف والهمزات
  وعلامات التشكيل، التساهل النهائي المدروس وبعض قواعد حالة الأحرف.
- **No cleaning (`raw`)**: قياس خط الأساس بعد تجهيز حدود العرض
  والمسافات واستخراج نص الترجمة فقط، وليس مقارنة بايتات خام.

يحسب Python كلا الوضعين، ويحفظ إعدادات السياسة والنتائج وسجل
التحويلات. لا تُعاد كتابة نتيجة سابقة تلقائيًا؛ استخدم **Re-score**
للحصول على قياس بسياسة مختلفة *دون استدعاء ASR من جديد*.

## حدود هذا الأسلوب

قد تساوي القواعد النهائية كلمات مختلفة، مثل «قوة» و«قوت»، أو تخفي
فرق ياء آخر الكلمة. لذلك استخدم **No cleaning** لمراجعة النتائج،
ولا تعتبر انخفاض WER بعد التطبيع دليلًا على تحسّن نموذج ASR نفسه.
ولا يُقاس الفهم الطبي أو جودة SOAP هنا.
